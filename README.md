## Project overview

This project explores the relationship between study hours and exam scores using 13 supplied observations. It includes a software development plan, numerical analysis with NumPy, data inspection with Pandas, visualizations with Matplotlib, and a linear regression model with scikit-learn. The notebook evaluates predictions using mean absolute error and discusses practical limitations.

The dataset is defined directly in the notebook; no separate data download is required.

## Run locally

Use Python 3 and install the dependencies:

```sh
python -m pip install -r requirements.txt
```

Start Jupyter:

```sh
jupyter notebook Hind_Alhmoudi_Assignment1.ipynb
```

Run the cells from top to bottom. The submitted notebook already contains saved outputs, so running it is optional for viewing the work.
